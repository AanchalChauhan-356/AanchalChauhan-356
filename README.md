### 01. 🌸 Subscription Retention Intelligence System

**Understanding customer behaviour through Machine Learning.**

What if businesses could identify customers who might leave before they actually do?

This project explores that question through an end-to-end machine learning application that predicts subscription customer churn and helps identify customers who may require retention attention.

Using customer information and predictive modeling, the application estimates churn probability, categorizes customer risk and presents retention recommendations through an interactive dashboard.

**What I explored:**
- Customer churn prediction using Logistic Regression.
- Data processing and feature preparation.
- Customer risk segmentation.
- Predictive probability and classification.
- Retention recommendations.
- Interactive analytics and visualizations.
- CSV-based prediction workflows.

**Tech Stack:** Python · Pandas · NumPy · Scikit-learn · Logistic Regression · Streamlit · Plotly
